# OpenAI Codex

You do not need to install anything to begin. Use the prompt in the repository
[README](../../../README.md).

To make the process available as a reusable Codex skill, copy:

```text
set-up-your-system/adapters/openai-codex/SKILL.md
  -> .agents/skills/setting-up-team-context/SKILL.md
```

Keep `set-up-your-system/START-HERE.md` in the repository. The adapter points to
it so the process has one shared source.

Codex should notice skill changes automatically. Restart it if an update does
not appear.

Reference: [OpenAI Codex Skills](https://developers.openai.com/codex/skills)
