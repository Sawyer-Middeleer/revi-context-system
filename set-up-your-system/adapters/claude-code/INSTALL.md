# Claude Code

You do not need to install anything to begin. Use the prompt in the repository
[README](../../../README.md).

To make the process available as a reusable Claude Code skill, copy:

```text
set-up-your-system/adapters/claude-code/SKILL.md
  -> .claude/skills/setting-up-team-context/SKILL.md
```

Keep `set-up-your-system/START-HERE.md` in the repository. The adapter points to
it so the process has one shared source.

Ask naturally or use `/setting-up-team-context`.

Reference: [Claude Code Skills](https://code.claude.com/docs/en/skills)
