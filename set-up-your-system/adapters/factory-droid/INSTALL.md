# Factory Droid

You do not need to install anything to begin. Use the prompt in the repository
[README](../../../README.md).

To make the process available as a reusable Factory skill, copy:

```text
set-up-your-system/adapters/factory-droid/SKILL.md
  -> .factory/skills/setting-up-team-context/SKILL.md
```

Keep `set-up-your-system/START-HERE.md` in the repository. The adapter points to
it so the process has one shared source.

Start a new Droid session if the skill does not appear immediately. Ask
naturally or use `/setting-up-team-context`.

If Factory Droid and Codex use the same repository, install only the Codex
adapter under `.agents/skills`. Factory also recognizes that location.

Reference: [Factory Skills](https://docs.factory.ai/harness/skills)
